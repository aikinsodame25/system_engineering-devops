# 0x01. Shell, Permissions

## Description
This repository contains exercises and scripts to practice Linux shell commands and file permissions. Each task helps in understanding user management, file creation, ownership, groups, and permission management in Linux.

## Tasks
- 0-iam_betty: Switch to user betty.
- 1-who_am_i: Display the current username.
- 2-groups: Display all groups of the current user.
- 3-new_owner: Change owner of file hello to betty.
- 4-empty: Create an empty file hello.
- 5-execute: Add execute permission to owner of hello.
- 8-James_Bond: Set hello permissions to ---rwx.
- 9-John_Doe: Set hello permissions to -rwxr-x-wx.
- 11-directories_permissions: Add execute permission to all directories.
- 12-directory_permissions: Create directory my_dir with permissions 751.
- 13-change_group: Change group of hello to school.
